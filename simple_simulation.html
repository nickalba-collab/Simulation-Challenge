Python Code Used

import numpy as np

def monte_carlo_pi(n):
    x = np.random.uniform(-1, 1, n)
    y = np.random.uniform(-1, 1, n)
    inside = np.sum(x**2 + y**2 <= 1)
    return 4 * inside / n

# Run simulation with 10,000 points
np.random.seed(123)
pi_estimate = monte_carlo_pi(10000)
print(f"Estimated π: {pi_estimate:.6f}")

How It Works

The Monte Carlo method estimates π by:

  1. Generating random points in a square from -1 to 1
  2. Counting points that fall inside the unit circle (x² + y² ≤ 1)
  3. Using the ratio: π ≈ 4 × (points inside circle) / (total points)

Key Findings

  • Monte Carlo methods provide good approximations for complex integrals
  • Convergence improves with sample size
  • Visual inspection helps validate simulation results
  • With 10,000 points, we achieved 99.9998% accuracy
